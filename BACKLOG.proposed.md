# Proposed items (awaiting review)
# Promote the ones you want with: python scripts/promote.py [slug ...]

- [ ] `primers-heterodimer` Add forward/reverse primer heterodimer scoring to primers — The README promises dimer analysis, but primers only computes Tm and self-dimer potential. Heterodimer complementarity between the two primers in a pair is a common cause of primer-dimer artifacts and failed amplification; a simple pair score would catch it before ordering. | proposed
- [ ] `phylogeny-upgma` Add UPGMA tree construction to phylogeny — The tool only performs neighbor-joining. UPGMA is a standard alternative for distance matrices under a molecular-clock assumption and is often requested for clustering lab isolates; adding it as a --method option broadens the tool without changing existing output. | proposed
- [ ] `qpcr-multiple-reference-genes` Support multiple reference genes in qPCR normalization — ΔΔCq currently uses one housekeeping gene. MIQE guidance recommends validating and often combining multiple reference genes; accepting a comma-separated list and normalizing to their geometric mean reduces error from a single unstable reference. | proposed
- [ ] `elisa-weighted-4pl` Add 1/y² weighted fitting to ELISA 4PL curves — Immunoassay response variance grows with signal, so ordinary least squares overweights high-OD standards. Optional weighting improves parameter estimates and low-concentration back-calculation, which matters for potency and impurity assays. | proposed
- [ ] `hplc-sst-acceptance-criteria` Add configurable SST acceptance criteria and pass/fail output — HPLC SST tables currently only print numbers. Labs must judge against USP <621> or method limits for plates, tailing, resolution, and %RSD; a criteria file or CLI thresholds with an overall PASS/FAIL would automate the suitability decision. | proposed
- [ ] `hemocytometer-clump-correction` Add cell clump correction to hemocytometer counts — Clumped cells are counted as one by a hemocytometer, underestimating concentration. An optional clumps-per-square or aggregate factor would correct viable cell counts and dilution calculations for primary-cell and yeast workflows. | proposed
- [ ] `growth-curve-blank-subtraction` Subtract blank/background OD in growth-curve analysis — Plate-reader OD data often needs blank correction. Fitting raw OD inflates A and distorts lag and μ; a --blank-well or blank-column option makes kinetic parameters comparable across plates and media. | proposed
- [ ] `media-fill-group-by` Add group-by analysis to media-fill contamination rates — Media-fill data are often analyzed by line, operator, or product family, not just batch. A --group-by column would compute per-group contamination rates, CIs, and trend tests, helping investigations pinpoint where aseptic failures cluster. | proposed
- [ ] `bioburden-spc-fixed-baseline` Allow fixed baseline control limits in bioburden-spc — I-MR charts currently recompute limits from every dataset. After a validated process change, labs need to lock limits from a historical baseline and plot new data against them; a --baseline CSV would prevent limit drift and enable proper trending. | proposed
- [ ] `pipette-cal-uncertainty` Report measurement uncertainty in pipette calibration — ISO 8655 pass/fail is not enough for ISO 17025-style reports; users need an uncertainty estimate for each volume. Adding an expanded uncertainty from repeatability and calibration data would make the tool suitable for accredited pipette calibration records. | proposed
