# Proposed items (awaiting review)
# Promote the ones you want with: python scripts/promote.py [slug ...]

- [ ] `elisa-5pl-model` Add 5-parameter logistic (5PL) option to ELISA curve fitting — Many immunoassay standard curves are asymmetric and fit better with a 5PL model; current tool only offers 4PL and log-log linear. Adding 5PL improves accuracy for plate-based assays and is a focused model extension. | proposed
- [ ] `hplc-sst-capacity-selectivity` Add capacity factor (k′) and selectivity (α) to HPLC SST — USP <621> system suitability often includes retention factor and selectivity, not just plates/tailing/resolution. Labs need these to judge column performance; requires a void time t0 input and adjacent-peak calculations. | proposed
- [ ] `qpcr-multiple-reference-genes` Support multiple reference genes in qPCR ΔΔCq normalization — MIQE guidelines recommend at least two stable housekeeping genes; a single reference gene can be regulated by treatment. Accepting a list and using the geometric mean Cq gives more reliable relative expression. | proposed
- [ ] `mpn-unequal-replicates` Allow unequal tube counts per dilution in MPN calculator — Real MPN designs often use different replicate numbers per dilution (e.g., 5×10 mL, 3×1 mL, 3×0.1 mL). Current equal-tubes restriction forces users to discard data or split calculations; supporting per-dilution n is a focused API/CLI change. | proposed
- [ ] `cfu-serial-dilution-planner` Add a serial dilution planning subcommand to cfu — Labs design dilution schemes before plating, not just analyze counts. A planner computing sample and diluent volumes for a target dilution series from stock concentration reduces manual C1V1 errors in bioburden/CFU workflows. | proposed
- [ ] `growth-curve-blank-subtraction` Add optional blank/control well subtraction to growth-curve — Raw OD readings include medium and plate blank absorbance; subtracting a blank well before logistic/Gompertz fitting improves parameter estimates. A blank-well column or value is a small, concrete preprocessing step. | proposed
- [ ] `bioburden-spc-trend-analysis` Add Mann-Kendall trend test and Theil-Sen slope to bioburden SPC — Western Electric rules flag special causes but not gradual drift, which matters for environmental monitoring and annual product reviews. A non-parametric trend p-value and slope give a quantitative signal for trending reports. | proposed
- [ ] `d-z-f0-sal-target` Add target SAL / required F0 calculation to d-z-f0 — Sterilization validation often specifies a target sterility assurance level (e.g., 10⁻⁶) and asks for the required F0 given bioburden and D121. This is a natural forward calculation from the existing D/Z/F0 tool. | proposed
- [ ] `sterility-direct-inoculation` Add direct inoculation media-volume support to sterility — USP <71> direct inoculation is still used for products unsuitable for membrane filtration and has distinct media volume rules. The current tool only sizes containers and sample units; adding direct inoculation guidance covers a common compendial method. | proposed
- [ ] `endotoxin-device-limits` Add medical-device endotoxin limit calculation per USP <161> — Device laboratories need EU/device limits based on contact category and extraction volume, which differ from parenteral drug limits. A focused subcommand extends the existing endotoxin tool to device testing. | proposed
