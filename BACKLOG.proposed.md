# Proposed items (awaiting review)
# Promote the ones you want with: python scripts/promote.py [slug ...]

- [ ] `primers-hairpin` Detect hairpin (stem-loop) secondary structures in the `primers` tool — The primers tool now detects 3' self-dimers, but intra-strand self-complementarity (hairpins) is another common cause of failed amplification, especially for longer primers. Computing stem length-weighted hairpin Tm and flagging structures above a threshold would catch primers that fold before they anneal. | proposed
- [ ] `restriction-type-iis` Support Type IIS enzymes (BsaI, BsmBI, BbsI) in `restriction` — The enzyme table only contains palindromic Type IIP sites, so Golden Gate and other Type IIS workflows cannot be simulated. Type IIS enzymes cut at a fixed offset outside a non-palindromic recognition site, which requires new recognition/spacer/cut-offset fields and correct fragment and overhang geometry. | proposed
- [ ] `phylogeny-fasta-distance` Build distance matrices directly from a multi-FASTA input in `phylogeny` — Users currently have to produce a PHYLIP matrix by hand, which blocks routine isolate comparisons. Adding p-distance / Jukes-Cantor computation from an aligned multi-FASTA lets the tool go from sequences to a tree in one step. | proposed
- [ ] `qpcr-reference-stability` Rank candidate reference genes with a GeNorm-style M-value in `qpcr` — ΔΔCq results are only as good as the reference gene; using an unstable housekeeper silently invalidates reported fold changes. Computing the pairwise-variation M-value across candidate reference genes and reporting a stability ranking guides users to a defensible normalization choice. | proposed
- [ ] `bioburden-ewma` Add an EWMA control chart option to `bioburden-spc` — I-MR charts are insensitive to small sustained shifts in environmental bioburden. An EWMA chart with configurable λ detects drifts earlier and is a standard SPC tool in validated trending programs. | proposed
- [ ] `d-z-f0-bi-fraction-negative` Estimate biological-indicator D-values from fraction-negative/survival data in `d-z-f0` — BI qualification often yields fraction-negative endpoints rather than a full log-reduction series, and the standard Spearman-Karber estimator is not available. Adding a `bi` subcommand lets labs derive D and F0 from BI enumeration data as required for sterilization validation. | proposed
- [ ] `endotoxin-device-limit` Add USP <161> medical-device endotoxin limit computation to `endotoxin` — The tool covers parenteral drug products but not devices, which use a different formula (EL = K × N / V). Device manufacturers need the per-device EU limit and the extraction-volume MVD, not the drug-dose formula. | proposed
- [ ] `hplc-sst-acceptance` Add configurable acceptance-criteria evaluation (PASS/FAIL) to `hplc-sst` — The tool prints SST metrics but no verdict, leaving analysts to apply USP/EP limits manually. Accepting thresholds for plates, tailing, resolution and %RSD and emitting an overall PASS/FAIL with the failing criterion called out closes the loop for GMP system-suitability reports. | proposed
- [ ] `elisa-weighted-fit` Add weighted 4PL regression to the `elisa` curve fitter — ELISA response variance grows with signal, so unweighted least squares biases the low end of the curve and its confidence intervals. Supporting 1/y² weighting via curve_fit's sigma argument improves back-calculated concentrations without changing the default CLI behavior. | proposed
- [ ] `sterility-bf-test` Evaluate bacteriostasis/fungistasis results in the `sterility` tool — USP <71>/EP 2.6.1 require a B/F test to demonstrate the article does not inhibit growth, but the tool only computes sample sizes. Adding a mode that compares indicator-organism growth in the test article versus the positive control and flags inhibition completes the sterility-test workflow. | proposed
